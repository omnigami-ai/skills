# Fennick Wordmark

Custom outlined capitals for the fictional Fennick brand. Generated by
`../../plans/refresh-brand.py` from the approved local `../wordmark.svg`
(Brewer’s seal, option 03), including the master’s letter spacing.
The C’s cubic curves are converted to quadratic curves at a maximum
0.005 source-unit error. This font contains only F, E, N, I, C, K and space.
It is used only when the editable name is exactly FENNICK; other names
use the bundled Bricolage font. No third-party logo font is used.

The film loads the packaged TTF directly. Pillow and fontTools are needed
only to regenerate assets from the cast; they are not playback dependencies.
